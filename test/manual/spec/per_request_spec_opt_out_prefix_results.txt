Same-prefix GPU diagnosis, 2026-11-02
====================================

Conclusion
The two repeated first-divergence sites behind the previous 14 comparisons are
precision-sensitive target-logit tie flips. Both paths selected the correct
lowest-ID argmax of their own logits, and emitted IDs matched logprob IDs.
BF16 speculative warm decode tied its two leading candidates; FP16 removed both
ties and both paths selected the same tokens. No production sampling fix is
justified by these observations. This is bounded evidence, not a proof that
all attention/KV values or every configuration are correct. Keep the PR draft.
The historical exact-token E2E failure is not relabelled as a pass.

Environment and method
H100 SXM, pinned image from per_request_spec_opt_out_e2e_resume.txt. The Rust
preflight passed. Qwen2.5-1.5B-Instruct target, Qwen2.5-0.5B-Instruct draft,
STANDALONE, width 4, 3 steps, Triton attention, page 16, overlap enabled,
seed 0, greedy. Prefill/decode CUDA graphs disabled for this diagnosis.
Source: 9dbdeaaf plus the PREFIX_DTYPE/TF32-off diagnostic controls committed in
ce7b2dba. No production runtime patch was applied. Raw executed script and patch
are archived. Analysis and new unit regressions are from ce7b2dba.

For each dtype, target and speculative servers ran sequentially:
- warm_plain: three concurrent prompts (two opted out, one enabled on spec),
  max-new-tokens [8, 68, 68], with no logits capture.
- warm_probe: same inputs, synchronizing and saving full pre-sampling logits.
- fresh: exact saved token prefix, one next token from prefill.
- one-decode: prefix minus its last token, then two generated tokens. The first
  generated token matched the saved final prefix token in all four cases/dtype.
Cache was flushed before every case. The analyzer checks the ENTIRE prefix,
not just position and last input ID, before accepting a score comparison.
All 12 captured sites per dtype had identical prefixes, correct argmax, and
matching emitted IDs. All 12 HTTP responses per dtype passed emitted/logprob-ID
alignment. Unprobed and probed warm outputs agreed within each server/dtype.

The precision control substantially reduces score perturbations. It does not

Regression and diagnostic changes
- Real ordinary/root greedy sampler test covers exact ties (lowest-ID choice)
  and a strict positive margin that must not be rounded into a tie.
- Offline analyzer rejects wrong/short prefixes and non-finite logits, verifies
  actual emissions, and reports full-vocabulary deltas without pass tolerances.
- Existing strict cross-server token equality in the model smoke stays intact.
  These diagnostic results do not silently waive it or force a different token.
