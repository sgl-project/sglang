Pass criteria
- Driver prints MODEL_E2E_AND_KV_SMOKE_PASS and writes summary.json.
- Target, eager and graph modes complete, real mixed/all-opt-out batches appear.
- Opted-out rows retain exactly one token; enabled rows sometimes accept >1.
- Tested greedy opted-out token IDs match the target-only baseline in this setup.
- Page/pool checks and draft-extend probes complete; graph mode observes forward
  graph rounds, eager mode does not. Short rows finish while longer rows remain;
  prefixes/cache slots are reused and cache is flushed before another wave.
- No assertion failures, leaks, illegal CUDA accesses or server exceptions.

Scope limits
Dense STANDALONE only, Qwen2.5 1.5B target / 0.5B draft, greedy output with EOS
ignored. This does NOT cover EOS/cancellation transport, stochastic E2E, EAGLE3,
HiSparse, TP/PP/DP, or a performance benchmark. Diagnostic synchronizations and
page/pool invariants do not prove every draft KV tensor value is correct. Do not
convert these bounded checks into a general cross-server determinism guarantee.
