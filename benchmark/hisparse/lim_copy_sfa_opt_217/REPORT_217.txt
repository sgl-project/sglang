Changes
-------
1. Copy-SFA consumes contiguous native LIM [B,32768] miss rows directly.
   TopK sources/slots and miss metadata share the native plan buffers;
   there is no second residency planner and no six-buffer repacking.
2. Graph batch scratch capacity is independent of request-ID capacity.
   Batch outputs, selected KV and metadata are charged to the HBM budget
   using the padded capacity; persistent per-request residency stays bounded
   by the real request pool.
3. Full-visible mode skips unused combined_kv/combined_ids tail workspaces.
4. Empty fallback attention rows are explicitly zeroed. The vendor SFA
   kernel may leave skipped-row output unwritten; padding must not publish it.
5. Native Copy-SFA gains dynamic TND, combined-tail row-stride handling and
   the dense C=0 miss-count guard. Framework dispatch remains Q1.
6. Native direct-plan/dynamic-TND tests and padded-graph framework validation
   cover the new contracts. A fixed-input Copy-SFA benchmark is included.

Fixed-input A/B measurement
--------------------------
This measures the indexer/manager/attention subpath, without checkpoint model
projections, scheduler or sampling. It is not an end-to-end serving speedup.
B=4, context parameter=8192 (one visible decode token), two attention layers,
32 index heads, 8 query heads, BF16, C=K=2048, alternating 1024-miss hotsets.
The same script, inputs, full-visible policy and environment were used with
the base source/wheel pair and optimized source/wheel pair in separate
processes. Each reports five graph timing samples after warmup.

Latency decreased 8.9581%. The manager's torch.npu.memory_allocated() delta

Selected IDs match between runs, and both pass bitwise resident-payload and
CPU attention checks. Raw samples and counts are in baseline.json and
optimized.json.

Reproduction
------------
Build/install the matching new kernel branch before using the new SGLang
branch. The old Q1 kernel host does not accept 32768-wide miss rows.

Kernel:
  bash build.sh -a kernels Ascend910_9382
  python3 -m pytest tests/python/sgl_kernel_npu/test_fused_lightning_indexer_manage.py tests/test_sparsity_driven_kv_cache_planner.py tests/test_copy_sfa_combined.py tests/test_lim_copy_sfa.py tests/test_copy_sfa_dynamic_tnd.py -q

SGLang:
  python3 test/registered/unit/hardware_backend/test_npu_lim_state.py -v
  python3 test/manual/npu/test_sparse_kv_offload_cache.py -v
  python3 benchmark/hisparse/check_lim_copy_sfa.py --output /tmp/framework.json
  python3 benchmark/hisparse/check_lim_copy_sfa.py --padded-batch --output /tmp/padded.json
  python3 benchmark/hisparse/bench_lim_copy_sfa.py --output /tmp/bench.json
