Fixes verified
- Publish speculative KV at absolute positions; mask rejected extend columns.
- Obtain query width from speculative metadata. TP token padding is a suffix,
  not extra query columns: a 2x3 window padded to 8 must not overwrite position 0.
- Pad missing indexer rows with -1 while preserving K, rather than reshaping K.
- Pack short TopK destinations as a contiguous alias of existing KV scratch.
- Compact invalid source IDs while preserving valid KV order and causality.
  Exact FP32 ordinal keys avoid the reported integer ArgSort AiCPU fallback.
- Invalidate stale residency for rewritten drafts; reset both managers on reuse.
- Give the draft backend its own KV pool explicitly. EAGLE shares the target
  allocator's token IDs, so allocator.get_kvcache() is not the draft's KV pool.
  The previous two managers could alias the target host KV and misprice draft HBM.
- Price target and draft managers, index-scale scratch, and eager TP padding
  consistently before admitting requests. Draft backends share one draft manager.
