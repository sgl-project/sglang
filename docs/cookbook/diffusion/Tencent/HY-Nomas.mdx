## 1. Quick start

Follow the [SGLang Diffusion installation guide](/docs/sglang-diffusion/installation) on Linux with NVIDIA CUDA. Official distilled, non-quantized checkpoints have been exercised through the offline API, HTTP video API and realtime WebSocket service on H200. The built-in [HF overlay](https://huggingface.co/Niehen6174/Hy-Nomas-overlay) prepares the model automatically; no conversion script is required.

```bash
uv pip install -e 'python[diffusion]'

# HTTP video jobs and realtime WebSocket sessions share the same pipeline.
sglang serve --model-path tencent/Hy-Nomas --num-gpus 1 --port 30000
```

On first load, the shared overlay loader downloads the pinned distilled DiT,
PixelUMM_FT and Qwen2.5-VL-7B-Instruct text encoder, then caches the assembled
pipeline under `SGLANG_DIFFUSION_CACHE_ROOT`. DiT/text weights are linked or
copied; PixelUMM's decoder is exported without changing tensor values or dtypes.
PE and quantized variants are excluded. Already-prepared local pipeline
directories are also accepted. Use structured event JSON with trained weights;
plain captions only exercise the protocol.

Single-GPU and SP=2 runs passed the recorded checks. TP=2 completes requests but
trained-weight parity with single GPU remains unresolved. The
[validation guide](https://github.com/sgl-project/sglang/blob/main/python/sglang/multimodal_gen/test/scripts/README.nomas.md)
records the measured scope and limitations; those H200 results are manual checks,
not CI results.

## 2. Model capabilities

HY-Nomas generates video one event segment at a time. Each segment is denoised with 8 Euler steps (flow shift 5, no classifier-free guidance) while attending to the K/V cache of retained earlier segments. When a segment's K/V is needed for continuation, its latent is re-noised with sigma 0.207 and forwarded once more to write the cache; the last offline segment skips this by default. Text comes from a Qwen2.5-VL encoder (`hidden_states[-3]`, 1280 tokens per event) and is cached together with the video tokens; later events see only the head of an earlier event's JSON, not its action list. An optional per-frame camera token is injected after every block. PixelUMM decodes the f32t4c32 latents to pixels with a 10-latent window and 5-latent overlap.

The model directory holds `tokenizer/`, `text_encoder/` (Qwen2_5_VLForConditionalGeneration), `transformer/` (NomasTransformer3DModel), `vae/` (NomasPixelUMMDecoder, `decoder.*` weights only) and `scheduler/` (FlowMatchEulerDiscreteScheduler with `shift: 5.0`), with `model_index.json` naming `NomasPipeline`.

## 3. Offline requests

Each request plans its events, generates them in order with a request-local KV cache, decodes once and returns one video. Model-specific fields go through the Python API:

From the repository root, use the checked-in two-event request (240 frames at
352×640, eight steps, seed 42):

```python
import json
from pathlib import Path

from sglang.multimodal_gen import DiffGenerator

request = json.loads(Path(
    "python/sglang/multimodal_gen/test/single_test_file/fixtures/nomas_two_events.json"
).read_text())
with DiffGenerator.from_pretrained(model_path="tencent/Hy-Nomas") as generator:
    result = generator.generate({**request, "save_output": True})
```


| Field | Meaning |
| --- | --- |
| `segments` | One event per entry; `frames` sum to `num_frames`. The first event's caption replaces `prompt`. |
| `prompt_format` | `json` applies the upstream event schema (head-only history, per-action video windows); `plain` is a smoke-test shortcut and logs a warning. |
| `norm_extrinsics` | Already-normalized camera matrices on the canonical `(L-1)*4+1` timeline; the server does not normalize raw poses. |
| `continuation_prompts` | Legacy alternative to `segments`: fixed 10-latent events with one caption each. |

Dimensions align up to a multiple of 16, then down to 32 (720 becomes 704), as upstream. Any frame count is accepted; the decoder output is cropped to it.

## 4. Realtime session

Start the server and open `ws://HOST:PORT/v1/realtime_video/generate`. Messages are MessagePack maps. The server keeps one live session; its DiT KV cache, noise bank and decode context persist across chunks and are released when the client disconnects.

| Message | Direction | Content |
| --- | --- | --- |
| `{"type": "init", "prompt": ..., "num_frames": ..., "size": "1280x704", "num_inference_steps": 8, "condition_inputs": {"prompt_format": "json", "segments": [...]}}` | client | Starts the session. Without `segments`, `prompt` and `num_frames` form the first event. |
| `{"type": "event", "kind": "segment", "event_id": n, "payload": {"caption": ..., "frames": ..., "norm_extrinsics": ...}}` | client | Queues the next event. `norm_extrinsics` holds `(latents-1)*4+1` matrices for this event only. |
| `{"type": "event", "kind": "end"}` | client | No more events: the server emits the withheld frames and closes. |
| `frame_batch` / `frame_batch_header` | server | Raw RGB (or webp/jpeg) frames, chunk-indexed. A chunk may carry no frames. |

The generation loop waits for an event, denoises it as one segment and writes its K/V. Its initial noise is sliced from a per-session bank by absolute latent position; the bank, its growth and every cache noise come from one generator seeded with the request seed, in upstream's order.

Decoding follows upstream's stable-prefix PixelUMM streaming (`WindowStreamingDecodeSession.push`/`finish`). Every event's latents are appended to one session timeline; 10-latent windows on a fixed 5-latent stride are decoded as soon as they are complete, with noise drawn by absolute latent index. A frame is sent only once no later window can overlap it, and the `end` flush sends the rest, so no frame is ever revised. Concatenated, the frames a session sends equal one full decode of all its latents, with each event cut to its requested `frames` (17+32+9 frames yields 58, not 64). Frames therefore lag generation: a first event shorter than one window sends nothing until the timeline reaches 10 latents.

The prompt enhancer (Nomas-PE) is a separate LLM service. The client calls it to turn user text and the previous frames into the next event JSON, then sends that JSON as the `caption`; `examples/nomas/realtime_client.py` drives a session from prepared captions.

### KV cache budget

The session cache starts at `interactive_kv_cache_initial_tokens` (65536) and grows by `interactive_kv_cache_growth_factor` (1.5) up to `max_cache_gib` (32 GiB) or free memory minus `cache_free_memory_reserve_gib` (8 GiB). When the budget is reached, or when `max_cache_segments` is set, the oldest event is evicted FIFO exactly as upstream does at cache-write time: the current event is denoised against the full history, the oldest segment is dropped, and the new K/V is written against the remaining history. The RoPE frame offset keeps counting across evictions. The cache grows first and evicts only once the budget is reached, including after `max_cache_segments` has dropped older events. If the cache forward fails after an eviction has already rewritten the history, the cache is marked invalid and the session has to be restarted. All of these are `NomasPipelineConfig` fields.

At 1280x704 one 10-latent event costs about 4.5 GB of K/V on a single GPU; tensor and sequence parallelism divide that per rank.

## 5. Parallelism and offload

```bash
# Tensor parallel: every linear in the double-stream blocks is head-sharded.
sglang serve --model-path tencent/Hy-Nomas --num-gpus 2 --tp-size 2

# Ulysses sequence parallel: video tokens sharded, text replicated, as upstream.
sglang serve --model-path tencent/Hy-Nomas --num-gpus 8 --sp-degree 8

# Layerwise offload of the DiT blocks (the 54 small camera modules stay resident).
sglang serve --model-path tencent/Hy-Nomas --dit-layerwise-offload true
```

`tp_size * sp_degree` must divide the 16 attention heads. Ring attention, data parallelism and CFG parallelism are rejected. TP and SP can be combined. The multi-GPU frame alignment the framework applies to time-sharded models is disabled for Nomas (`adjust_frames=False`), so event frame counts are preserved.

## 6. Not implemented

No I2V (upstream starts from noise too), no PE service inside the server, no raw camera normalization, no ring attention, no multi-session serving, no CFG, no KV CPU swap, no sliding-window history policies and no INT8 KV. The test matrix lives in `python/sglang/multimodal_gen/test/unit/test_nomas*.py`.
