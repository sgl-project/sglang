## 2. Model capabilities

[Stable Diffusion XL base 1.0](https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0) is Stability AI's latent-diffusion text-to-image model. A 2.6B-parameter UNet conditions on two text encoders, CLIP ViT-L and OpenCLIP ViT-bigG, and generates 1024x1024 images natively. It also conditions on the original image size and crop coordinates, which SDXL uses to reduce cropping artifacts.

Choose it when you need a widely adopted open-weight image model with a small footprint: the full pipeline fits on one 24GB GPU. It is a classifier-free-guidance model that runs about 30 to 50 denoising steps, so it is slower per image than distilled models such as Z-Image-Turbo. SGLang serves the base model only; the refiner stage is not supported.

The model is released under the [CreativeML Open RAIL++-M License](https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0/blob/main/LICENSE.md).

SGLang runs the UNet in bf16, the text encoders in fp16, and the VAE in fp32 by default. The SDXL VAE overflows in fp16, so keep it in fp32. SGLang's automatic memory policy chooses where the smaller components live: on the 24GB Arc Pro B60 it keeps the text encoders in host memory, and on a 40GB A100 it streams the text encoders and VAE layer by layer from pinned host memory. The UNet stays on the GPU in both cases.

You can override component precision at startup with `--dit-precision`, `--text-encoder-precisions`, and `--vae-precision`. The bf16 UNet runs about 10x faster than fp32 on the Arc Pro B60 and about 2.6x faster on the A100 (see [Benchmark](#5-benchmark)).

An empty negative prompt produces zero negative embeddings, matching the Diffusers default for SDXL base (`force_zeros_for_empty_prompt`). Pass a non-empty negative prompt to use text-conditioned negative guidance instead.

## 4. Request examples

For the complete API, see the [OpenAI-compatible API guide](/docs/sglang-diffusion/api/openai_api).

```python Example
import base64

from openai import OpenAI

client = OpenAI(api_key="EMPTY", base_url="http://localhost:30000/v1")

response = client.images.generate(
    model="stabilityai/stable-diffusion-xl-base-1.0",
    prompt="A beautiful sunset over the ocean, photorealistic",
    n=1,
    response_format="b64_json",
)

with open("output.png", "wb") as f:
    f.write(base64.b64decode(response.data[0].b64_json))
```

## 5. Benchmark

Both platforms run the same workload: 1024x1024, 30 steps, guidance scale 7.5, seed 42, and the prompt "a beautiful sunset over the ocean, photorealistic". Each row is one cold `sglang generate` request in a fresh process, not a serving benchmark, so end-to-end time includes one-time startup costs:

```shell Command
sglang generate --model-path stabilityai/stable-diffusion-xl-base-1.0 \
    --prompt "a beautiful sunset over the ocean, photorealistic" \
    --height 1024 --width 1024 --num-inference-steps 30 --guidance-scale 7.5 --seed 42 \
    --save-output
```

The accuracy reference is the Diffusers `StableDiffusionXLPipeline` in full fp32 on the same GPU, started from the same initial latents. The VAE runs in fp32 in every configuration.
