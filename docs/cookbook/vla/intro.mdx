SGLang Diffusion supports action generation alongside image, video, and audio generation. Action models map camera observations, language instructions, and robot state into continuous action chunks using the same `multimodal_gen` runtime. Each recipe in this section carries one of two tags:

- **dVLA**: a diffusion Vision-Language-Action policy. A vision-language backbone encodes the observation, and an action head denoises the action chunk.
- **WAM**: a world action model. A video diffusion backbone denoises future video latents jointly with the action chunk.

See the [action API](/docs/sglang-diffusion/api/openai_api#action-generation-sglang-extension) for shared endpoints and [Cosmos3](/cookbook/diffusion/Cosmos/Cosmos3) for world-model action generation. For the world models and simulators used alongside these policies, see [Robotics & Physical AI](/cookbook/use-cases/robotics-physical-ai).
