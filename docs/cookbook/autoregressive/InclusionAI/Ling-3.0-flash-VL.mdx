## 1. Model Introduction

Ling-3.0-flash-VL is the vision-language member of the BailingMoeV3 family. Its language backbone is the [Ling-3.0-flash](/cookbook/autoregressive/InclusionAI/Ling-3.0-flash) hybrid-attention Mixture-of-Experts (MoE) model: 42 layers that interleave Kimi Delta Attention (KDA) linear-attention layers with gated Multi-head Latent Attention (MLA) full-attention layers, on top of a fine-grained MoE feed-forward network with 512 routed experts (8 active per token) plus a shared expert. A 27-layer vision encoder (0.4B parameters, 16-pixel patches with 2×2 spatial merging and paired frames for video) feeds image and video tokens into that backbone through a small MLP projector. In total the checkpoint holds **~125B parameters with ~5.1B active per token**, so per-token inference cost stays close to a small model.

It is a thinking model: the chat template turns chain-of-thought on by default and exposes an `enable_thinking` switch. Inputs are text, images, and video; audio is not supported. Native context length is 128K tokens. Unlike Ling-3.0-flash, the VL checkpoint ships no built-in MTP draft layer, so there is no speculative-decoding recipe.

**Available Models:**

- **BF16**: [inclusionAI/Ling-3.0-flash-VL](https://huggingface.co/inclusionAI/Ling-3.0-flash-VL) — ~125B total / ~5.1B active

**License:** MIT

**Recommended generation:** `temperature=1.0`, `top_p=0.95`, `top_k=20` (from the checkpoint's `generation_config.json`; SGLang applies these defaults, so the samples below do not set them).

**Resources:** [HuggingFace](https://huggingface.co/inclusionAI/Ling-3.0-flash-VL).

## 2. Configuration Tips

- `--trust-remote-code` is required. The checkpoint declares its config and multimodal processor through `auto_map`, and SGLang's native implementation loads the image/video preprocessing and the chat template from those files.
- The remote processor imports its helper module (`bailingmm_utils`) by absolute name, so the checkpoint directory must be importable by the server process. When you serve from a local snapshot, launch with `PYTHONPATH=<snapshot-dir>` in front of the generated command. The same applies to `bench_serving`, which loads the processor client-side to count vision tokens.
- BF16 weights take ~250 GB. The recipes use `--tp 2` on 288 GB-class GPUs (GB300, B300), `--tp 4` on B200 / H200, and `--tp 8` on H100, all with `--mem-fraction-static 0.85`. Only the 2×GB300 recipe has been validated end to end; the other cells are sized by the same rule and carry the unverified badge. Adjust TP in the **Attention Parallelism** card of the [Playground](#playground).
- Vision token budget: the encoder emits one token per 32×32-pixel block after merging, so a 1280×720 image costs about 880 tokens and the processor's `max_pixels` of 4,194,304 caps a single image at roughly 4,100 tokens. Video frames are paired before patching; the sample clip in §3.2 costs 4,224 tokens. Size `--chunked-prefill-size` and `--max-running-requests` with these counts in mind for image-heavy traffic.
- Thinking is on by default. The chat template ends the prompt with `<think>`, so the generated `content` starts with the reasoning and switches to the answer after `</think>` (see §3.1). Turn it off per request with `"chat_template_kwargs": {"enable_thinking": false}` (§3.3), or enable `--reasoning-parser ling3` (toggle **Reasoning Parser** in the **Parsers** card of the [Playground](#playground)) to have the server return the reasoning in `message.reasoning_content` and only the answer in `message.content`.
- Native context is 128K; SGLang reads `max_position_embeddings` from the checkpoint's text config, so no `--context-length` flag is needed.
- Audio content parts are rejected before preprocessing; send images as `image_url` and clips as `video_url` content parts (§3).
- No FP8 or FP4 checkpoints are published for this model, so the matrix is BF16 only.

## 3. Advanced Usage

### 3.1 Image Understanding

Send images as OpenAI-style `image_url` content parts. With thinking on (the default), the reasoning arrives inline in `message.content`, terminated by `</think>`:

<Accordion title="Image Example (Python)">

```python Example
from openai import OpenAI

client = OpenAI(base_url="http://localhost:30000/v1", api_key="EMPTY")
resp = client.chat.completions.create(
    model="inclusionAI/Ling-3.0-flash-VL",
    messages=[{
        "role": "user",
        "content": [
            {"type": "image_url", "image_url": {"url": "https://raw.githubusercontent.com/sgl-project/sglang/main/examples/assets/example_image.png"}},
            {"type": "text", "text": "Describe this image in one sentence."},
        ],
    }],
    max_tokens=2048,
)
print(resp.choices[0].message.content)
```

</Accordion>

<Accordion title="Example Output">

```text Output
The user wants me to describe this image in one sentence. Let me look at the image carefully: a man wearing a yellow shirt is ironing clothes on an ironing board set up on the back of a yellow taxi (SUV type), with another yellow taxi passing by on the street, and there are buildings in the background.

I need to summarize this in one sentence.</think>A man in a yellow sweatshirt irons clothes on an ironing board attached to the back of a yellow taxi on a city street, while another yellow cab drives past.
```

</Accordion>

The opening `<think>` tag is part of the prompt, so it is not echoed back. With `--reasoning-parser ling3` the text before `</think>` moves to `message.reasoning_content` and `message.content` holds only the final sentence.

### 3.2 Video Understanding

Clips go in as `video_url` content parts. The processor samples and pairs frames itself; no client-side frame extraction is needed:

<Accordion title="Video Example (Python)">

```python Example
from openai import OpenAI

client = OpenAI(base_url="http://localhost:30000/v1", api_key="EMPTY", timeout=900)
resp = client.chat.completions.create(
    model="inclusionAI/Ling-3.0-flash-VL",
    messages=[{
        "role": "user",
        "content": [
            {"type": "video_url", "video_url": {"url": "https://github.com/sgl-project/sgl-test-files/raw/refs/heads/main/videos/jobs_presenting_ipod.mp4"}},
            {"type": "text", "text": "What is happening in this video? Answer in two sentences."},
        ],
    }],
    max_tokens=2048,
)
print(resp.choices[0].message.content)
```

</Accordion>

<Accordion title="Example Output">

```text Output
The user wants me to describe what's happening in this video in two sentences. Let me analyze the video frames.

The video shows Steve Jobs on stage at what appears to be an Apple keynote event. He's standing in front of a large screen showing a close-up of a hand reaching into a jeans pocket and pulling out a device. The text on screen asks about a pocket, and Jobs reveals it's the new iPod Nano. He holds up the thin iPod Nano device and shows how slim it is. The large screen behind him magnifies his presentation.

Let me write a concise two-sentence summary.</think>Steve Jobs is on stage at an Apple keynote, presenting the new iPod Nano by pulling it out of his jeans pocket in front of a large screen displaying a magnified view of the action. He holds up the remarkably thin device to the audience, demonstrating its slim profile while the screen behind him zooms in for a closer look.
```

</Accordion>

### 3.3 Thinking Mode

Disable chain-of-thought for a single request through the chat template's `enable_thinking` kwarg; the model then answers directly:

<Accordion title="Thinking-off Example (Python)">

```python Example
from openai import OpenAI

client = OpenAI(base_url="http://localhost:30000/v1", api_key="EMPTY")
resp = client.chat.completions.create(
    model="inclusionAI/Ling-3.0-flash-VL",
    messages=[{
        "role": "user",
        "content": [
            {"type": "image_url", "image_url": {"url": "https://raw.githubusercontent.com/sgl-project/sglang/main/examples/assets/example_image.png"}},
            {"type": "text", "text": "Describe this image in one sentence."},
        ],
    }],
    max_tokens=512,
    extra_body={"chat_template_kwargs": {"enable_thinking": False}},
)
print(resp.choices[0].message.content)
```

</Accordion>

<Accordion title="Example Output">

```text Output
A man in a yellow shirt irons clothes on a folding board attached to the back of a yellow taxi SUV while another taxi drives by on a city street.
```

</Accordion>
