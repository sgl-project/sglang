## Deployment

<a id="install" />

<Accordion title="Install SGLang">

```bash Command
docker pull lmsysorg/sglang:muse-spark-1.2
```

The deployment panel can render a complete `docker run` command for the selected hardware and options. See [Install SGLang with Docker](/docs/get-started/install#method-3-using-docker) for host setup.

</Accordion>

Choose your hardware and deployment options below. The default is **B300 / NVFP4 / TEP 4**. **H200**, **MI355X**, and **Xeon** are placeholders; launch commands are not available yet.

**TEP Size** sets both tensor and expert parallelism. BF16 requires TEP 8. On GB300, TEP 8 spans two nodes; replace `<node-rank>` and `<node0-ip>` for each node.

**Dflash V2** is enabled by default. Replace `<draft_model_id>` with your draft checkpoint, or select **Off**. The default **fp8_e4m3** KV cache selection adds no override flag. With PD disaggregation enabled, **L1+L2(Host)** adds HiCache only to the prefill worker.
