## 1. Model Introduction

**Clef** and **Clef-Flash** are decision models from Cloudflare, post-trained from Qwen3.8-27B and Qwen3.5-9B under the Apache-2.0 license. Each keeps its backbone and vision encoder and adds a small joint schema head that reads the backbone's final hidden states. One prompt holds the state and every question with its allowed options. The head routes evidence from the state to each option, lets the questions attend to each other, and returns one logit per allowed option of every question, without generating text.

**Resources:** [Clef](https://huggingface.co/Cloudflare/clef), [Clef-Flash](https://huggingface.co/Cloudflare/clef-flash).

## 2. Configuration Tips

- **Route.** Send requests to `/v1/systemone`. Clients of the System One API, including the TypeSafe SDKs, work by pointing their base URL at the server. See [System One compatible API](/docs/supported-models/decision_models#system-one-compatible-api) for the request and response reference. `/v1/decisions`, chat, and generation requests are refused, because the checkpoint answers through its head rather than its language model head.
- **One prefill per request.** All questions of a request share one prompt, so the state is read once however many questions you ask. SGLang serves these checkpoints in embedding mode without radix cache, chunked prefill, or CUDA graphs, and with `--tp-size 1`.
- **Answers.** `probabilities` are the softmax of the head's logits for each question, and `confidence` uses the same formulas as other models on this route. Answers omit `x_label_mass`, because the head scores only the allowed options.
- **Long states.** The prompt, images included, holds at most 16,384 tokens, the default `max_length` of the checkpoint's reference `encode_record`, or fewer when the server's context length, KV cache, or `--max-prefill-tokens` is smaller. A longer state is truncated so that every question still fits, as in the reference code.
- **Images.** Pass each image in `images` as a data URL, such as `data:image/jpeg;base64,...`, or as an HTTP(S) URL. A bare base64 JPEG starts with `/`, which the shared image loader reads as a file path, so the request fails. Images precede the state, as in the reference code.

## 3. Advanced Usage

### 3.1 Text Decisions

<Accordion title="Text Decision Example (Python)">

```python Example
import requests

response = requests.post(
    "http://localhost:30000/v1/systemone",
    json={
        "model": "Cloudflare/clef",
        "state": "My Stripe integration keeps failing. I'm losing sales. Please help ASAP.",
        "questions": {
            "routing": {
                "type": "choice",
                "instructions": "Which team should handle this request?",
                "criteria": {
                    "billing": "Charges and refunds",
                    "technical_support": "Integration errors",
                    "sales": "Questions about buying a product",
                },
            },
            "urgency": {"type": "noul", "instructions": "Does this message express urgency?"},
            "frustration": {
                "type": "score",
                "instructions": "How frustrated is the customer?",
                "criteria": ["Calm", "Frustrated but civil", "Very angry"],
            },
        },
    },
    timeout=60,
)
response.raise_for_status()
for name, answer in response.json()["answers"].items():
    print(name, answer)
```
