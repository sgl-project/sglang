## 1. Model Introduction

[Step-5-Preview](https://huggingface.co/stepfun-ai/Step-5-Preview) is a multimodal Mixture-of-Experts reasoning model from StepFun. The language model has 92 layers with 352 routed experts (top-8) plus a shared expert, and interleaves sliding-window attention (window 512) with full-attention layers at a 3:1 ratio. The full-attention layers use sparse attention: a lightweight indexer selects the top-512 compressed KV blocks for each query. The model supports up to 1M tokens of context, ships 3 MTP layers for speculative decoding, and includes a vision encoder for image input. Weights are FP8 (E4M3, 128×128 block scales) and released under the Apache-2.0 license.

**Resources:** [HuggingFace](https://huggingface.co/stepfun-ai/Step-5-Preview).

## 2. Configuration Tips

- **KV cache.** Every recipe uses BF16 KV cache. On Blackwell, FP8 KV cache (`--kv-cache-dtype fp8_e4m3`, full-attention layers only) is available in the Playground; it increases KV capacity but is lossy. H200 supports BF16 KV cache only.
- **MegaMoE.** The Balanced recipe moves routed experts to DeepGEMM MegaMoE (`--moe-a2a-backend megamoe`, Blackwell only), which targets batched serving; for single-request latency use the Low-Latency recipe. MegaMoE also supports TP8/EP8 with attention DP 2 on B300.
- **DP-Attention.** The High-Throughput recipe runs TP8 with attention DP 2 and EP8. Other EP sizes are not supported with DP-Attention. The recipe uses eager prefill. B300 TP8/EP8 with attention DP 2, MegaMoE, BF16 KV, and MTP also supports `--cuda-graph-backend-prefill breakable`. With attention DP enabled, the vision encoder and projector use replicated weights.
- **FlashInfer.** The FlashInfer TRT-LLM MoE path and the TP4 all-reduce fusion need the Step5 FlashInfer patches under `docker/patches/step5` (base patches in `docker/patches/step5/base`); see the README there.
- **First start.** The first launch compiles FlashInfer modules (about 15 minutes on B300); later launches take about 6 minutes. Persist `FLASHINFER_WORKSPACE_BASE` and `~/.cache/sglang` across restarts.
- **H200.** The FP8 weights (about 650 GB) do not fit TP4 on H200, so the H200 recipe uses TP8/EP8 with FA3 attention and Triton MoE.
- **HiCache.** Size `--hicache-ratio` to the host memory available per rank. On B300 with TP8, a ratio of 1.5 fits.

## 3. Advanced Usage

### 3.1 Reasoning

Step-5-Preview always thinks before answering. The `step5` reasoning parser (already in every recipe) returns the thinking in `reasoning_content` and the answer in `content`.

<Accordion title="Reasoning Example (Python)">

```python Example
from openai import OpenAI

client = OpenAI(base_url="http://localhost:30000/v1", api_key="EMPTY")
resp = client.chat.completions.create(
    model="stepfun-ai/Step-5-Preview",
    messages=[{"role": "user", "content": "What is 15% of 240?"}],
)
msg = resp.choices[0].message
print("Reasoning:", msg.reasoning_content)
print("Answer:", msg.content)
```

### 3.2 Tool Calling

The `step5` tool-call parser (already in every recipe) returns structured tool calls in `message.tool_calls`.

<Accordion title="Tool Calling Example (Python)">

```python Example
import json
from openai import OpenAI

client = OpenAI(base_url="http://localhost:30000/v1", api_key="EMPTY")
tools = [{
    "type": "function",
    "function": {
        "name": "get_weather",
        "description": "Get the current weather for a city",
        "parameters": {
            "type": "object",
            "properties": {"city": {"type": "string", "description": "City name"}},
            "required": ["city"],
        },
    },
}]
messages = [{"role": "user", "content": "What's the weather like in Beijing right now?"}]

resp = client.chat.completions.create(
    model="stepfun-ai/Step-5-Preview", messages=messages, tools=tools,
)
msg = resp.choices[0].message
print("Tool calls:", msg.tool_calls)

call = msg.tool_calls[0]
messages.append(msg)
messages.append({
    "role": "tool",
    "tool_call_id": call.id,
    "content": json.dumps({"city": "Beijing", "temperature_c": 18, "condition": "Sunny"}),
})
final = client.chat.completions.create(
    model="stepfun-ai/Step-5-Preview", messages=messages, tools=tools,
)
print("Reasoning:", final.choices[0].message.reasoning_content)
print("Answer:", final.choices[0].message.content)
```

### 3.4 HiCache (Hierarchical KV Caching)

For long multi-turn sessions, enable hierarchical KV caching in the **Hierarchical KV Cache** card of the [Playground above](#playground) to keep evicted prefixes in host memory. See the HiCache sizing note in [Configuration Tips](#2-configuration-tips).
