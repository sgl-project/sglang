## Deployment

<a id="install" />

<Accordion title="Install SGLang">

```bash Command
docker pull lmsysorg/sglang:beam
```

For host setup, see [Install SGLang with Docker](/docs/get-started/install#method-3-using-docker). The command panel below has a **Python / Docker** toggle, with Python selected by default. The Python output is the bare `sglang serve` command: run it inside a container started from this image. The Docker output wraps the same command in `docker run`.

</Accordion>

Select your hardware, strategy, and quantization to generate the launch command.

- **Low-Latency** uses TP with the [DFlash2 drafter](https://huggingface.co/reflection/Beam-1.0-501B-A23B-DFlash2) at block size 8.
- **High-Throughput** disables DFlash2. H200 BF16 uses TP8 with an automatic static memory fraction; the other recipes use TP + DPA. B300 and GB300 NVFP4 also enable EP and FlashInfer MegaMoE.
- **RTX PRO 6000** serves NVFP4 only, with TP4 and DFlash2 in both strategies; High-Throughput raises the running-request limit to 64. The recipe enables FlashInfer's PCIe-IPC all-reduce, since these GPUs have no NVLink.

Each GSM8K score covers all 1,319 test problems; the benchmark notes identify the evaluation harness.

NVFP4 requires Blackwell: B300, GB300, or RTX PRO 6000. On four RTX PRO 6000 GPUs the KV cache holds about 150K tokens, so the recipe caps the context at 128K tokens. **GB300 BF16 uses two four-GPU nodes**: set the head-node address and node rank in **Env**, then run the command on both nodes with rank 0 on the head and rank 1 on the peer.

## TPU Support

Beam 1.0 has day-0 TPU support through SGLang-TorchTPU, a native PyTorch backend for LLM, VLM, and diffusion model inference on TPUs. It combines TPU acceleration with SGLang features such as RadixAttention and HiCache to enable cost-efficient, production-ready serving for agentic workloads.

## Usage

All recipes serve the model as `beam` on port 30000. For GB300 BF16, connect to the head node.

<Accordion title="Chat completion (Python)">

```python Example
from openai import OpenAI

client = OpenAI(base_url="http://localhost:30000/v1", api_key="EMPTY")
response = client.chat.completions.create(
    model="beam",
    messages=[{"role": "user", "content": "Explain tensor parallelism briefly."}],
)
message = response.choices[0].message
print("Reasoning:", message.reasoning_content)
print("Answer:", message.content)
```
