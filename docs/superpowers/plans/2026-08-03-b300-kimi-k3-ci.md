# B300 Kimi-K3 Base-C CI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an always-on 8-GPU B300 base-C suite that runs the Kimi-K3 Low Latency and Balanced recipes and requires at least 0.95 GSM8K accuracy for each recipe.

**Architecture:** Extend the existing `stage` plus `runner_config` CI registry with an `8-gpu-b300` runner and a `base-c-test-8-gpu-b300` primary workflow job. Add one model E2E test file with two independent `CustomTestCase` classes so both launch recipes run sequentially on the same eight-GPU runner and report failures independently.

**Tech Stack:** Python `unittest`, SGLang CI registry and server test helpers, `GSM8KMixin`, GitHub Actions reusable workflows, YAML runner configuration, pre-commit.

## Global Constraints

- Register the test with `stage="base-c"` and `runner_config="8-gpu-b300"`.
- Add B300 only to the primary per-commit workflow; do not modify `pr-test-extra.yml`.
- Use `/data/radixark/model-cache/hub/models--moonshotai--Kimi-K3/snapshots/9f62e4e9fffbd0a83ddd60e1c209d828994b3569` as the target model path.
- Keep `RadixArk/Kimi-K3-DSpark` as the Low Latency draft model identifier.
- Run 200 GSM8K examples for each recipe and require a score of at least `0.95`.
- Preserve the requested launch arguments exactly, including Balanced `--mamba-full-memory-ratio 7.21`.
- Use `CustomTestCase` and defensive process cleanup.
- Do not change production serving code or add unrelated refactors.
- This is a CI configuration and E2E test-only change; use registry/configuration validation instead of an artificial production-code red/green unit test.

- [ ] **Step 2: Create the registered model E2E test**

Create `test/registered/models_e2e/test_kimi_k3_b300.py` with exactly this structure:

```python
"""B300 per-commit CI coverage for Kimi-K3 serving recipes.

Runs the Low Latency DSPARK recipe and the Balanced DCP/HiCache recipe on
eight B300 GPUs. Each server must preserve basic model quality on GSM8K.
"""

import unittest

from sglang.srt.utils import kill_process_tree
from sglang.test.ci.ci_register import register_cuda_ci
from sglang.test.kits.eval_accuracy_kit import GSM8KMixin
from sglang.test.test_utils import (
    DEFAULT_URL_FOR_TEST,
    CustomTestCase,
    popen_launch_server,
)

register_cuda_ci(est_time=1800, stage="base-c", runner_config="8-gpu-b300")

MODEL_PATH = (
    "/data/radixark/model-cache/hub/models--moonshotai--Kimi-K3/"
    "snapshots/9f62e4e9fffbd0a83ddd60e1c209d828994b3569"
)
DSPARK_DRAFT_MODEL = "RadixArk/Kimi-K3-DSpark"
SERVER_LAUNCH_TIMEOUT = 3600


class TestKimiK3B300LowLatency(GSM8KMixin, CustomTestCase):
    """TP8 Low Latency recipe with DSPARK linear ReplaySSM speculation."""

    gsm8k_score_threshold = 0.95
    gsm8k_num_examples = 200

    @classmethod
    def setUpClass(cls):
        cls.model = MODEL_PATH
        cls.base_url = DEFAULT_URL_FOR_TEST
        cls.process = popen_launch_server(
            cls.model,
            cls.base_url,
            timeout=SERVER_LAUNCH_TIMEOUT,
            other_args=[
                "--trust-remote-code",
                "--tp-size",
                "8",
                "--mem-fraction-static",
                "0.85",
                "--reasoning-parser",
                "kimi_k3",
                "--tool-call-parser",
                "kimi_k3",
                "--mamba-full-memory-ratio",
                "0.86",
                "--speculative-algorithm",
                "DSPARK",
                "--speculative-draft-model-path",
                DSPARK_DRAFT_MODEL,
                "--speculative-dspark-block-size",
                "7",
                "--enable-linear-replayssm-spec",
            ],
        )

    @classmethod
    def tearDownClass(cls):
        if hasattr(cls, "process") and cls.process:
            kill_process_tree(cls.process.pid)


class TestKimiK3B300Balanced(GSM8KMixin, CustomTestCase):
    """TP8/DCP8 Balanced recipe with hierarchical cache."""

    gsm8k_score_threshold = 0.95
    gsm8k_num_examples = 200

    @classmethod
    def setUpClass(cls):
        cls.model = MODEL_PATH
        cls.base_url = DEFAULT_URL_FOR_TEST
        cls.process = popen_launch_server(
            cls.model,
            cls.base_url,
            timeout=SERVER_LAUNCH_TIMEOUT,
            other_args=[
                "--trust-remote-code",
                "--tp-size",
                "8",
                "--dcp-size",
                "8",
                "--disable-custom-all-reduce",
                "--mem-fraction-static",
                "0.85",
                "--reasoning-parser",
                "kimi_k3",
                "--tool-call-parser",
                "kimi_k3",
                "--mamba-full-memory-ratio",
                "7.21",
                "--enable-hierarchical-cache",
            ],
        )

    @classmethod
    def tearDownClass(cls):
        if hasattr(cls, "process") and cls.process:
            kill_process_tree(cls.process.pid)


if __name__ == "__main__":
    unittest.main()
```
