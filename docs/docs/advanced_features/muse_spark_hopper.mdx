On SM90 GPUs, Muse Spark NVFP4 with DFlash serves with Hopper kernels: fused W4A16 experts, fused
FP8-KV attention, token-tree verify, sequence-parallel prefill and small-M GEMVs. They keep the stock
precision (only fp32 accumulation order may differ) and need compute capability 9.0; other GPUs and
models keep the stock code.

## Switches

`SGLANG_MUSE_SPARK_HOPPER_KERNELS=0` turns off the fused kernels and the model paths built on them.
With it on (default), the Muse Spark hook also sets these on SM90, unless already set:

| Variable | Value |
|---|---|
| `SGLANG_HOPPER_SMALL_M_GEMV`, `SGLANG_OPT_CUDA_GRAPH_FILL_FAST_PATH` | `1` |
| `SGLANG_ENABLE_DFLASH_MIXED_VERIFY` | `1` |
| `SGLANG_INPUT_LOGPROB_MAX_CHUNK_TOKENS` | `16384` |
| `NCCL_CUMEM_ENABLE` (single node, TP > 1) | `1` |

## Launch on 8x H200

```bash Command
SGLANG_ALLOW_OVERWRITE_LONGER_CONTEXT_LEN=1 python -m sglang.launch_server \
  --model-path meta-models/Muse-Spark-Open-816B-A42B-NVFP4 \
  --speculative-algorithm DFLASH --speculative-draft-model-path RadixArk/Muse-Spark-Open-DFlash2 \
  --speculative-num-draft-tokens 8 --speculative-draft-attention-backend fa4 \
  --tp-size 8 --ep-size 8 --quantization modelopt_fp4 --moe-runner-backend marlin \
  --mem-fraction-static 0.85 --context-length 131072 --max-running-requests 32 \
  --cuda-graph-max-bs-decode 32 --enable-hierarchical-cache --hicache-size 120 \
  --chunked-prefill-size 32768 --max-prefill-tokens 32768 --enable-mixed-chunk \
  --schedule-policy shortest-prefill-first --swa-full-tokens-ratio 0.09 \
  --disable-cuda-graph-padding --enable-prefill-delayer --prefill-delayer-queue-min-ratio 0.2 \
  --prefill-delayer-max-delay-ms 100 --prefill-delayer-max-delay-passes 6 \
  --prefill-max-requests 32
```
