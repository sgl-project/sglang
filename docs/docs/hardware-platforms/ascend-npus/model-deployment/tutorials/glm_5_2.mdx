## Introduction

GLM-5.2 is a large language model in the GLM (General Language Model) series, jointly developed by the KEG Laboratory
of Tsinghua University and Zhipu AI. GLM-5.2 adopts the DeepSeek-V3/V3.2 architecture, including DeepSeek Sparse
Attention (DSA) and multi-token prediction (MTP), and supports high-throughput inference with SGLang on Ascend NPUs.

This document demonstrates the deployment of GLM-5.2 on Ascend NPUs using SGLang, including single-node deployment,
multi-node deployment, prefill-decode disaggregation, feature configuration, and performance optimization.

## Supported features

| Feature                       | Example usage                                                                     |
|-------------------------------|-----------------------------------------------------------------------------------|
| Tensor Parallelism            | `--tp-size 16`                                                                    |
| Data Parallelism              | `--dp-size 16`                                                                    |
| Expert Parallelism            | `--ep-size 16 \`<br/>`--moe-a2a-backend deepep \`<br/>`--deepep-mode auto`         |

## MegaMoE on A3 with BF16 or INT experts

Use `--moe-a2a-backend ascend_fuseep --fuseep-mode 3` for fused dispatch,
expert GEMMs, activation, and combine on Atlas A3 (`Ascend910_93`).
The adapter uses the layer's configuration rather than a model-name allowlist.
Compatible GLM, Kimi, and other MoE layers can use these combinations:

| Expert format | Quantization setting | Activation | Expert bias |
| --- | --- | --- | --- |
| BF16 | No quantization flag; BF16 checkpoint | SwiGLU or SiTU | Unsupported |
| W8A8 INT | `--quantization modelslim`, per-channel scales | SwiGLU or SiTU | Unsupported |
| W4A8 INT | `--quantization modelslim`, per-channel scales | SwiGLU or SiTU | Loaded compensation required |

Hidden states must be BF16 for every format. Ordinary SwiGLU is selected by
`activation="silu"` or `"swiglu"`. Kimi's SiTU is selected by `"situ"` or
`"situglu"`, with `gemm1_alpha` forwarded as `beta` (default 4.0) and
`gemm1_clamp_limit` forwarded as `linear_beta`. A `None` clamp remains unclamped;
the adapter does not replace it with a fixed Kimi default.

Keep shared experts separate with `--disable-shared-experts-fusion`.
Speculative decoding, expert load balancing, input-side router weighting,
non-gated/no-combine execution, clipped SwiGLU, SwiGLU-OAI, and other activation
contracts are rejected. FP8, MXFP and FP4 layouts are not reinterpreted as INT
weights: the current DeepEP A3 MegaMoE path exposes BF16 and INT modes, while
A5 MXFP formats require a separate platform/layout adapter. Groupwise INT scales,
activation clipping, nonzero weight offsets, mixed projection formats and BF16
expert biases are unsupported.

Use matching CANN toolkit/operator packages and DeepEP exposing
`FuseMode.MEGA_MOE` and `Buffer.fused_deep_moe(..., fuse_mode=3, activation=...,
l1_bias=..., l2_bias=...)`. The MegaMoE JIT extension requires `ninja`.
If the operator rejects `activation_params`, upgrade the CANN toolkit and its
matching `cann_ops_transformer` operator package instead of applying a legacy
DeepEP patch. The recorded API reference environment loads both ACL and MegaMoE
from **CANN 9.2.0-beta.2**. A version label alone is insufficient: verify the
actual imported module and accepted keywords in the serving environment.
Keep PyTorch and `torch_npu` compatible with the selected toolkit; no separate
Torch upgrade is implied by this keyword mismatch.

After sourcing the selected CANN `set_env.sh`, check the serving Python:

```bash
python3 - <<'PY_CHECK'
import inspect
import cann_ops_transformer
import deep_ep
from cann_ops_transformer.ops import mega_moe

print("operator package:", cann_ops_transformer.__file__)
print("DeepEP:", deep_ep.__file__)
inspect.signature(mega_moe).bind_partial(
    activation="swiglu", activation_params=None
)
assert {"fuse_mode", "quant_mode", "activation", "beta", "linear_beta", "l1_bias", "l2_bias"} <= set(
    inspect.signature(deep_ep.Buffer.fused_deep_moe).parameters
)
print("Required Python APIs available; device validation is still required")
PY_CHECK
```

SGLang neither patches dependency sources nor replaces DeepEP strategy methods.

The following eager recipe uses a compatible ModelSlim INT checkpoint on one
A3 node with 16 dies and MoE EP16/TP1. For BF16 experts, use an unquantized BF16
checkpoint and omit `--quantization modelslim`; do not reinterpret packed INT
checkpoint weights as BF16. Model activation settings are read from its MoE
configuration, including Kimi's SiTU parameters.

```bash
export MODEL_PATH=/path/to/GLM-5.2-modelslim-int
export SGLANG_DEEPEP_NUM_MAX_DISPATCH_TOKENS_PER_RANK=512
export SGLANG_NPU_ENABLE_DSA_TOKEN_SHARD=0

python3 -m sglang.launch_server \
    --model-path "$MODEL_PATH" \
    --trust-remote-code \
    --device npu --attention-backend ascend \
    --quantization modelslim --dtype bfloat16 \
    --tp-size 16 --ep-size 16 \
    --moe-a2a-backend ascend_fuseep --fuseep-mode 3 \
    --disable-shared-experts-fusion \
    --chunked-prefill-size 512 --max-running-requests 16 \
    --context-length 8192 --mem-fraction-static 0.82 \
    --disable-cuda-graph --host 0.0.0.0 --port 30000
```

This is a validation recipe, not a measured performance recommendation. Select
a compatible full-weight BF16, W4A8 INT or W8A8 INT checkpoint. A3 expert
intermediate dimensions up to 3584 are accepted with the existing 512 alignment;
remaining geometry and platform constraints are checked before conversion or by
CANN. The dispatch capacity must be
identical across ranks and within `[1, 4096]`; it bounds each rank's input rows,
including prefill. The scheduler chunk is global, so verify logged rank-local
rows before increasing either limit. Older native operators size workspace from
the configured capacity even for tiny batches.

The native workspace-reuse fix is upstream in CANN
[merge request !11324](https://gitcode.com/cann/ops-transformer/merge_requests/11324)
(`c465a55ac0cd`). Verify that the installed native build contains it; accepting
the Python API does not prove workspace reuse. No native CANN backport or
dependency patch is bundled in SGLang.

Run the dependency's existing numerical tests in a matching built environment:

```bash
export DEEP_EP_ROOT=/path/to/sgl-kernel-npu
for quant in w4a8 w8a8; do
    python3 "$DEEP_EP_ROOT/tests/python/deepep/test_mega_moe.py" \
        --num-processes 16 --quant-mode "$quant" --activation swiglu \
        --num-tokens 1024 --hidden 6144 --moe-intermediate-size 2048 \
        --num-experts 256 --num-topk 8
done
```

These operator tests do not establish full-model quality or NPUGraph replay
correctness. For a TP baseline, replace the FuseEP flags and `--ep-size 16` with
`--moe-a2a-backend none --ep-size 1`. Keep attention TP16, checkpoint, graph mode,
shared-expert setting, and workload identical, and record the MoE topology change.
Check prefill/decode accuracy before enabling graphs, then validate capture and
repeated changing-shape replay separately. Record resolved arguments, runtime
identity, TTFT, TPOT, and peak memory. Target-A3 acceptance of the BF16/INT and
SwiGLU/SiTU combinations remains pending; host matrix tests do not establish
full-model quality.

## MegaMoE on A5 with MXFP experts

The same `--moe-a2a-backend ascend_fuseep --fuseep-mode 3` interface supports
Ascend 950 MXFP experts through the existing DeepEP/CANN MegaMoE operator.
This adapter builds on the A3 integration and reuses the MXFP quantizers; no
additional native kernel or dependency patch is included. It requires a
DeepEP build containing [sgl-kernel-npu #873](https://github.com/sgl-project/sgl-kernel-npu/pull/873),
matching CANN 9.2 toolkit/operator packages exposing the A5 MegaMoE API, and
compatible PyTorch/torch_npu with E8M0 and packed-FP4 support.

| Expert format | Checkpoint/setting | DeepEP mode |
| --- | --- | --- |
| W8A8 MXFP8 E4M3 | ModelSlim offline or `--quantization mxfp8` online | `mx_fp8_e4m3` |
| W4A8 MXFP4 | ModelSlim offline | `mx_fp8_e4m3_w4` |
| W4A4 MXFP4 | ModelSlim offline | `mx_fp4_e2m1` |

Use a checkpoint whose surrounding layers are also supported by its existing
quantization configuration. E5M2, online FP4 conversion, mixed W13/W2 formats,
expert biases and additional checkpoint formats are outside this adapter.
SwiGLU and SiTU retain their model-configured semantics and the restrictions
listed above. Shared experts must remain separate; MoE TP must be 1.

A5 preparation retains `[E,N,K]` weights and ND E8M0 scales
`[E,N,K/64,2]`, rather than the transpose views used by ordinary GMMs. MXFP8
uses ND weights; packed FP4 uses the projection-specific NZ conversions required
by CANN. `SGLANG_NPU_DISABLE_ACL_FORMAT_WEIGHT=1` is rejected for FP4.
A5 receives BF16 inputs at their actual local length; DeepEP owns quantization
and dispatch. Set the same positive dispatch capacity on every rank, at least
as large as the maximum local batch. A3's 4096-token limit does not apply to A5;
installed CANN geometry/capacity constraints still apply.

For example, adapt the A3 recipe to a compatible A5 checkpoint and node:

```bash
export MODEL_PATH=/path/to/a5-modelslim-mxfp-checkpoint
export SGLANG_DEEPEP_NUM_MAX_DISPATCH_TOKENS_PER_RANK=8192
python3 -m sglang.launch_server \
  --model-path "$MODEL_PATH" --trust-remote-code \
  --device npu --dtype bfloat16 --quantization modelslim \
  --tp-size 8 --ep-size 8 \
  --moe-a2a-backend ascend_fuseep --fuseep-mode 3 \
  --disable-shared-experts-fusion \
  --chunked-prefill-size 8192 --disable-cuda-graph
```

This is an eager validation starting point, not an established model-support or
performance result. Before enabling graphs, compare the same checkpoint against
the existing unfused A5 path for numerical quality, prefill/decode and repeated
unequal rank-local batches. Record runtime identity, resolved flags, activation,
TTFT, TPOT, throughput and peak memory. Changing-shape graph replay, memory
stability and full-model A5 acceptance remain pending.

## Online service deployment

### Single-node deployment

Quantized model `GLM-5.2-w8a8` can be deployed on one Ascend A3 Series node.

Run the following script to execute online inference.

```shell
# ============================================================
# Before running, update the following variables:
#   MODEL_PATH: path to the model weights directory
# ============================================================

# high performance cpu
echo performance | tee /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor
sysctl -w vm.swappiness=0
sysctl -w kernel.numa_balancing=0
sysctl -w kernel.sched_migration_cost_ns=50000
# bind cpu
export SGLANG_SET_CPU_AFFINITY=1

unset https_proxy
unset http_proxy
unset HTTPS_PROXY
unset HTTP_PROXY
unset ASCEND_LAUNCH_BLOCKING
# cann
source /usr/local/Ascend/ascend-toolkit/set_env.sh
source /usr/local/Ascend/nnal/atb/set_env.sh

export STREAMS_PER_DEVICE=32
export SGLANG_DISAGGREGATION_BOOTSTRAP_TIMEOUT=600
# MTP OVERLAP
export SGLANG_ENABLE_OVERLAP_PLAN_STREAM=1
export SGLANG_NPU_USE_MULTI_STREAM=1

export HCCL_BUFFSIZE=1000
export HCCL_OP_EXPANSION_MODE=AIV
export HCCL_SOCKET_IFNAME=lo
export GLOO_SOCKET_IFNAME=lo
# DEEPEP
export DEEPEP_NORMAL_LONG_SEQ_ROUND=72
export DEEPEP_NORMAL_LONG_SEQ_PER_ROUND_TOKENS=1024
export DEEPEP_NORMAL_COMBINE_ENABLE_LONG_SEQ=1
export DEEP_NORMAL_MODE_USE_INT8_QUANT=1

MODEL_PATH=/path/to/model-weights

python3 -m sglang.launch_server \
        --model-path $MODEL_PATH \
        --attention-backend ascend \
        --device npu \
        --tp-size 16 --nnodes 1 --node-rank 0 \
        --chunked-prefill-size 16384 --max-prefill-tokens 280000 \
        --trust-remote-code \
        --host 127.0.0.1 \
        --mem-fraction-static 0.7 \
        --port 8000 \
        --served-model-name glm-5 \
        --cuda-graph-bs-decode 16 \
        --quantization modelslim \
        --speculative-draft-model-quantization unquant \
        --speculative-algorithm NEXTN --speculative-num-steps 3 --speculative-eagle-topk 1 --speculative-num-draft-tokens 4  \
        --moe-a2a-backend deepep --deepep-mode auto
```

### Multi-node deployment

Quantized model `GLM-5.2-w8a8` can be deployed on two Ascend A3 Series nodes.

Modify the IP addresses of the two nodes, then run the same script on both nodes.

```shell
# ============================================================
# Before running, update the following variables:
#   IPS: IP addresses of each node in the cluster
#   IP_MASTER: rank 0 node IP address with port
#   MODEL_PATH: path to the model weights directory
#   HCCL_SOCKET_IFNAME: network interface name for HCCL
#   GLOO_SOCKET_IFNAME: network interface name for Gloo
# ============================================================

echo performance | tee /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor
sysctl -w vm.swappiness=0
sysctl -w kernel.numa_balancing=0
sysctl -w kernel.sched_migration_cost_ns=50000
# bind cpu
export SGLANG_SET_CPU_AFFINITY=1

unset https_proxy
unset http_proxy
unset HTTPS_PROXY
unset HTTP_PROXY
unset ASCEND_LAUNCH_BLOCKING
# cann
source /usr/local/Ascend/ascend-toolkit/set_env.sh
source /usr/local/Ascend/nnal/atb/set_env.sh

export STREAMS_PER_DEVICE=32
export SGLANG_DISAGGREGATION_BOOTSTRAP_TIMEOUT=600
# MTP OVERLAP
export SGLANG_ENABLE_OVERLAP_PLAN_STREAM=1

export SGLANG_NPU_USE_MULTI_STREAM=1
export HCCL_BUFFSIZE=1000
export HCCL_OP_EXPANSION_MODE=AIV

# Run command ifconfig on two nodes, find out which inet addr has same IP with your node IP. That is your public interface, which should be added here
export HCCL_SOCKET_IFNAME=<network-interface>
export GLOO_SOCKET_IFNAME=<network-interface>

# DEEPEP
export DEEPEP_NORMAL_LONG_SEQ_ROUND=72
export DEEPEP_NORMAL_LONG_SEQ_PER_ROUND_TOKENS=1024
export DEEPEP_NORMAL_COMBINE_ENABLE_LONG_SEQ=1
export DEEP_NORMAL_MODE_USE_INT8_QUANT=1


IPS=('<your node1 ip>' '<your node2 ip>')
IP_MASTER="${IPS[0]}:5000"

MODEL_PATH=/path/to/model-weights

LOCAL_HOST1=`hostname -I|awk -F " " '{print$1}'`
LOCAL_HOST2=`hostname -I|awk -F " " '{print$2}'`
for i in "${!IPS[@]}";
do
    if [[ "$LOCAL_HOST1" == "${IPS[$i]}" || "$LOCAL_HOST2" == "${IPS[$i]}" ]];
    then
        echo "${IPS[$i]}"
        python3 -m sglang.launch_server \
        --model-path $MODEL_PATH \
        --attention-backend ascend \
        --device npu \
        --tp-size 32 --nnodes 2 --node-rank $i --dist-init-addr $IP_MASTER \
        --chunked-prefill-size 16384 --max-prefill-tokens 131072 \
        --trust-remote-code \
        --host 127.0.0.1 \
        --mem-fraction-static 0.8 \
        --port 8000 \
        --served-model-name glm-5 \
        --cuda-graph-max-bs-decode 32 \
        --moe-a2a-backend deepep \
        --deepep-mode auto \
        --speculative-draft-model-quantization unquant \
        --speculative-algorithm NEXTN --speculative-num-steps 3 --speculative-eagle-topk 1 --speculative-num-draft-tokens 4  \
        --disable-radix-cache
        NODE_RANK=$i
        break
    fi
done
```

### Prefill-decode disaggregation deployment

PD disaggregation splits the prefill and decode stages onto separate nodes, reducing interference and improving
throughput for high-concurrency scenarios.

```shell
# ============================================================
# Before running, update the following variables:
#   ASCEND_MF_STORE_URL: prefill master IP address with port
#   P_IP: prefill node IP address
#   D_IP: decode node IP address
#   MODEL_PATH: path to the model weights directory
#   HCCL_SOCKET_IFNAME: network interface name for HCCL
#   GLOO_SOCKET_IFNAME: network interface name for Gloo
# ============================================================

echo performance | tee /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor
sysctl -w vm.swappiness=0
sysctl -w kernel.numa_balancing=0
sysctl -w kernel.sched_migration_cost_ns=50000

export SGLANG_SET_CPU_AFFINITY=1

unset https_proxy
unset http_proxy
unset HTTPS_PROXY
unset HTTP_PROXY
unset ASCEND_LAUNCH_BLOCKING
source /usr/local/Ascend/ascend-toolkit/set_env.sh
source /usr/local/Ascend/nnal/atb/set_env.sh

export PYTORCH_NPU_ALLOC_CONF=expandable_segments:True
export STREAMS_PER_DEVICE=32
# pd transfer, prefill master IP
export ASCEND_MF_STORE_URL="tcp://<your prefill ip>:24707"
export SGLANG_DISAGGREGATION_BOOTSTRAP_TIMEOUT=600

P_IP=('<your prefill ip>')
D_IP=('<your decode ip>')

MODEL_PATH=/path/to/model-weights

export TRANSFORMERS_VERBOSITY=error

LOCAL_HOST1=`hostname -I|awk -F " " '{print$1}'`
LOCAL_HOST2=`hostname -I|awk -F " " '{print$2}'`
echo "${LOCAL_HOST1}"
echo "${LOCAL_HOST2}"

# prefill
for i in "${!P_IP[@]}";
do
    if [[ "$LOCAL_HOST1" == "${P_IP[$i]}" || "$LOCAL_HOST2" == "${P_IP[$i]}" ]];
    then
        echo "${P_IP[$i]}"
        export DEEPEP_NORMAL_LONG_SEQ_ROUND=72
        export DEEPEP_NORMAL_LONG_SEQ_PER_ROUND_TOKENS=1024
        export DEEPEP_NORMAL_COMBINE_ENABLE_LONG_SEQ=1
        export DEEP_NORMAL_MODE_USE_INT8_QUANT=1
        export TASK_QUEUE_ENABLE=2
        export HCCL_SOCKET_IFNAME=<network-interface>
        export GLOO_SOCKET_IFNAME=<network-interface>

        # prefill node
        python -m sglang.launch_server --model-path ${MODEL_PATH}  --disaggregation-mode prefill --host ${P_IP[$i]} \
        --port 8000 --disaggregation-bootstrap-port 8998 --trust-remote-code --nnodes 1 --node-rank $i \
        --tp-size 16 --mem-fraction-static 0.8 --attention-backend ascend --device npu --quantization modelslim \
        --disaggregation-transfer-backend ascend --max-running-requests 64 \
        --served-model-name glm-5 --chunked-prefill-size 524288 --max-prefill-tokens 180000 --moe-a2a-backend deepep --deepep-mode normal \
        --disable-shared-experts-fusion --disable-cuda-graph --dtype bfloat16 \
        --dp-size 4 --enable-dp-attention \
        --load-balance-method round_robin \
        --enable-dp-lm-head --moe-dense-tp 1 \
        --speculative-draft-model-quantization unquant \
        --speculative-algorithm NEXTN --speculative-num-steps 1 --speculative-eagle-topk 1 --speculative-num-draft-tokens 2

        # cp
        #--enable-prefill-cp \
        #--cp-strategy zigzag \
        #--attn-cp-size 4 \
        NODE_RANK=$i
        break
    fi
done

# decode
for i in "${!D_IP[@]}";
do
    if [[ "$LOCAL_HOST1" == "${D_IP[$i]}" || "$LOCAL_HOST2" == "${D_IP[$i]}" ]];
    then
        echo "${D_IP[$i]}"

        export SGLANG_ENABLE_OVERLAP_PLAN_STREAM=1
        export HCCL_BUFFSIZE=650

        export SGLANG_DEEPEP_NUM_MAX_DISPATCH_TOKENS_PER_RANK=32
        export TASK_QUEUE_ENABLE=0

        export HCCL_SOCKET_IFNAME=<network-interface>
        export GLOO_SOCKET_IFNAME=<network-interface>

        export SGLANG_NPU_USE_MULTI_STREAM=1

        python -m sglang.launch_server --model-path ${MODEL_PATH} --disaggregation-mode decode --host ${D_IP[$i]} \
        --port 8003 --trust-remote-code --nnodes 1 --node-rank $i --tp-size 16 --dp-size 16 --enable-dp-attention --ep-size 16 \
        --mem-fraction-static 0.8 --max-running-requests 128 --attention-backend ascend --device npu --quantization modelslim \
        --served-model-name glm-5 --moe-a2a-backend deepep --deepep-mode low_latency \
        --cuda-graph-max-bs-decode 4 --disaggregation-transfer-backend ascend --watchdog-timeout 9000 --context-length 180000 \
        --tokenizer-worker-num 4 --disable-shared-experts-fusion --dtype bfloat16  --load-balance-method round_robin \
        --speculative-draft-model-quantization unquant \
        --speculative-algorithm NEXTN --speculative-num-steps 3 --speculative-eagle-topk 1 --speculative-num-draft-tokens 4
        NODE_RANK=$i
        break
    fi
done
```

P_MASTER_IP="<your prefill ip>"

python3 -m sglang_router.launch_router \

--policy round_robin \

## Functional verification

After the service is started, you can invoke the model by sending a prompt:

```shell
# ============================================================
# Before running, update the following variables:
#   HOST: the server host address (e.g., localhost)
#   PORT: the server port number (e.g., 8000)
# ============================================================

curl http://${HOST}:${PORT}/generate \
    -H "Content-Type: application/json" \
    -d '{
        "text": "What is the capital of France?",
        "sampling_params": {
            "max_new_tokens": 64,
            "temperature": 0
        }
    }'
```

Expected result: an HTTP 200 response with the generated text containing "Paris".
