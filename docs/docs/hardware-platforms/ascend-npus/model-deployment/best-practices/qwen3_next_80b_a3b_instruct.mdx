### Qwen3-Next-80B-A3B-Instruct W8A8 1P IN3K5 OUT1K5 20ms

**Model**: Qwen3-Next-80B-A3B-Instruct

**Hardware**: A3 Series Products

**Cards**: 1

**Deploy Mode**: PD Mixed

**Quantization**: W8A8 INT8

**Dataset**: 3.5k+1.5k

**TPOT**: 20ms

#### Model Deployment

```bash Command
# ============================================================
# Before running, update the following variables:
#   MODEL_PATH: path to the model weights directory
#   DRAFT_MODEL_PATH: path to the draft model weights directory
#   HCCL_SOCKET_IFNAME: network interface name for HCCL
#   GLOO_SOCKET_IFNAME: network interface name for Gloo
# ============================================================

MODEL_PATH=/path/to/model-weights
DRAFT_MODEL_PATH=/path/to/draft-model-weights

echo performance | tee /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor
sysctl -w vm.swappiness=0
sysctl -w kernel.numa_balancing=0
sysctl -w kernel.sched_migration_cost_ns=50000

unset https_proxy
unset http_proxy
unset HTTPS_PROXY
unset HTTP_PROXY
unset ASCEND_LAUNCH_BLOCKING

source /usr/local/Ascend/ascend-toolkit/set_env.sh
source /usr/local/Ascend/nnal/atb/set_env.sh

export ASCEND_USE_FIA=1
export DEEPEP_HCCL_BUFFSIZE=2000
export DEEPEP_NORMAL_LONG_SEQ_PER_ROUND_TOKENS=2048
export DEEPEP_NORMAL_LONG_SEQ_ROUND=10
export FORCE_DRAFT_MODEL_NON_QUANT=1
export GLOO_SOCKET_IFNAME=<network-interface>
export HCCL_OP_EXPANSION_MODE=AIV
export HCCL_SOCKET_IFNAME=<network-interface>
export PYTORCH_NPU_ALLOC_CONF=expandable_segments:True
export SGLANG_DEEPEP_NUM_MAX_DISPATCH_TOKENS_PER_RANK=400
export SGLANG_ENABLE_OVERLAP_PLAN_STREAM=1
export SGLANG_ENABLE_TP_MEMORY_INBALANCE_CHECK=0
export SGLANG_NPU_USE_MULTI_STREAM=0
export SGLANG_SET_CPU_AFFINITY=1
export SGLANG_WARMUP_TIMEOUT=3600
export STREAMS_PER_DEVICE=32
export TASK_QUEUE_ENABLE=1
export ZBCCL_BOOTSTRAP_URL=tcp://127.0.0.1:24669
export ZBCCL_ENABLE_GRAPH=1
export ZBCCL_LOCAL_MEM_SIZE=60416
export ZBCCL_NPU_ALLOC_CONF=use_vmm_for_static_memory:True

python3 -m sglang.launch_server \
    --model-path $MODEL_PATH \
    --host 127.0.0.1 --port 6688 \
    --trust-remote-code \
    --attention-backend ascend \
    --device npu \
    --quantization modelslim \
    --page-size 128 \
    --tp-size 2 \
    --watchdog-timeout 9000 \
    --mem-fraction-static 0.85 \
    --disable-radix-cache \
    --max-prefill-tokens 28672 \
    --context-length 26384 \
    --max-total-tokens 122304 \
    --speculative-algorithm NEXTN \
    --speculative-num-steps 3 \
    --speculative-eagle-topk 1 \
    --speculative-num-draft-tokens 4 \
    --speculative-draft-model-quantization unquant \
    --chunked-prefill-size -1 \
    --max-running-requests 2 \
    --cuda-graph-bs-decode 2 \
    --mamba-ssm-dtype bfloat16 \
    --speculative-draft-model-path $DRAFT_MODEL_PATH \
    --reasoning-parser qwen3 \
    --tool-call-parser qwen3_coder
```

#### Multi-turn serving latency

On a single A3 card (TP2), a long prefill from the next chat turn can interrupt a request that is already streaming. To bound the time spent on each prefill and give active decodes time to advance, replace `--chunked-prefill-size -1` in the launch command above with these two arguments.

```bash
--chunked-prefill-size 1024 \
--prefill-decode-interval 2
```

To compare the two configurations, run the benchmark below once against each server on port 6688. Keep concurrency at two and vary the number of three-turn conversations. The generated shared-prefix dataset uses the group count and prompts per group to size the workload. Two and eight conversations produce six and 24 completed requests, respectively.

```bash
results=$(mktemp -d)
for conversations in 2 8 8 2 2 8; do
    python -m sglang.benchmark.serving \
        --backend sglang-oai-chat --base-url http://127.0.0.1:6688 \
        --tokenizer "$MODEL_PATH" --dataset-name generated-shared-prefix \
        --max-concurrency 2 --num-prompts "$conversations" \
        --gsp-num-groups 1 --gsp-prompts-per-group "$conversations" \
        --gsp-num-turns 3 --gsp-system-prompt-len 2048 --gsp-question-len 128 \
        --gsp-output-len 64 --gsp-range-ratio 1 --seed 42 \
        --warmup-requests 1 --flush-cache --output-details \
        --extra-request-body '{"stream_options":{"include_usage":true}}' \
        --output-file "$results/$conversations.jsonl" || break
done
```

Each JSONL file should contain three records. Pair them in file order, check `completed` for both workloads, and subtract the two-conversation `mean_tpot_ms` from the eight-conversation value. For device traces, run each workload separately with `--profile --profile-activities CPU GPU --profile-steps 32` and a distinct `--profile-output-dir` on the server.

On A3 with Qwen3-Next W8A8 and BF16 NEXTN weights, the following differences were measured on SGLang `0.5.21+npu` (commit `545ed1c6`). The bounded configuration included the [prefill interval fix](https://github.com/sgl-project/sglang/pull/46654).

| Server configuration | Pair 1 (ms) | Pair 2 (ms) | Pair 3 (ms) |
| --- | ---: | ---: | ---: |
| Chunking disabled, interval 0 | -61.713 | +2.013 | +2.079 |
| Chunk size 1024, interval 2 | +0.273 | +0.755 | +0.568 |

The first baseline pair included a 6.52-second inter-chunk gap in the two-conversation run. In the third eight-conversation run, bounded scheduling reduced mean TPOT from 19.15 to 17.94 ms, increased mean time to first token from 401 to 705 ms, and reduced output throughput from 79.19 to 69.53 tokens/s.
