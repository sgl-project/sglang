---
title: "Use Models From ModelScope"
---
To use a model from [ModelScope](https://www.modelscope.cn), set the environment variable `SGLANG_USE_MODELSCOPE`.

```bash Set Environment Variable
export SGLANG_USE_MODELSCOPE=true
```

We take [Qwen2-7B-Instruct](https://www.modelscope.cn/models/qwen/qwen2-7b-instruct) as an example.

Launch the Server:
```bash Python
python -m sglang.launch_server --model-path qwen/Qwen2-7B-Instruct --port 30000
```

Or start it by docker:

```bash Docker
docker run --gpus all \
    -p 30000:30000 \
    -v ~/.cache/modelscope:/root/.cache/modelscope \
    --env "SGLANG_USE_MODELSCOPE=true" \
    --ipc=host \
    lmsysorg/sglang:latest \
    python3 -m sglang.launch_server --model-path Qwen/Qwen2.5-7B-Instruct --host 0.0.0.0 --port 30000
```

Note that modelscope uses a different cache directory than huggingface. You may need to set it manually to avoid running out of disk space.

## Select the draft model source

`SGLANG_DRAFT_USE_MODELSCOPE` overrides the source for speculative draft models
and their token maps. When unset, it inherits `SGLANG_USE_MODELSCOPE`.
The tokenizer follows the main model's source; existing local paths are used directly.

| `SGLANG_USE_MODELSCOPE` | `SGLANG_DRAFT_USE_MODELSCOPE` | Main model | Draft model |
| --- | --- | --- | --- |
| `0` | unset | Hugging Face | Hugging Face |
| `1` | unset | ModelScope | ModelScope |
| `0` | `1` | Hugging Face | ModelScope |
| `1` | `0` | ModelScope | Hugging Face |

Use ordinary repository IDs in `--model-path` and `--speculative-draft-model-path`.
Hugging Face models keep the existing on-demand download behavior. ModelScope
models use the existing snapshot download behavior. A draft that reuses the
main model's local checkpoint continues to use that checkpoint.
