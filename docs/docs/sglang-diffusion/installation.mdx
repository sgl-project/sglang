---
title: Install SGLang Diffusion
description: Run SGLang's built-in diffusion engine with Docker, or install the diffusion extra with pip, uv, or from source.
---
SGLang Diffusion is SGLang's built-in image and video generation engine. It ships in the same [repository](https://github.com/sgl-project/sglang) and **`sglang` Python package**, using `sglang generate` and `sglang serve`.

Docker is recommended for Linux GPU deployments. The official NVIDIA images include the standard diffusion dependencies; no additional `pip install` is needed. For Python installation, use `sglang[diffusion]`: `[diffusion]` adds optional dependencies to the same package, not a separate engine. See the [cookbook](/cookbook/diffusion/intro) for model-specific dependencies and optional backends.

## Install on NVIDIA GPUs

These instructions target Linux with NVIDIA GPUs. For the driver, CUDA, and Python requirements, see [SGLang installation](/docs/get-started/install). Docker includes Python; no host Python installation is required. Choose one installation method below; other platforms have dedicated instructions further down this page.

<Tabs>
<Tab title="Docker (recommended)" id="method-3-using-docker">

Follow the shared [Docker setup](/docs/get-started/install#method-3-using-docker) to install the NVIDIA Container Toolkit and start an SGLang container. Use the latest stable image for released models, or a nightly image containing the required changes for unreleased models. Pin a release tag or image digest for reproducible deployments.

Inside the container, run [generation or serving commands](/docs/sglang-diffusion#quick-start) directly. Use `--host 0.0.0.0 --port 30000` when serving through the published container port. Mount an output directory to retain generated files after removing the container, and mount any local input media or checkpoints before using their container paths in requests.

</Tab>
<Tab title="pip / uv" id="method-1-with-pip-or-uv">

If SGLang is already installed, run the same installation command in that environment to add the diffusion dependencies.

Use uv for faster installation:

```bash Command
pip install --upgrade pip
pip install uv
uv pip install "sglang[diffusion]" --prerelease=allow
```

With pip, use:

```bash
pip install "sglang[diffusion]" --pre
```

</Tab>
<Tab title="From source" id="method-2-from-source">

Clone the SGLang repository and install its Python package with the diffusion extra:

```bash Command
# Clone the SGLang repository
git clone https://github.com/sgl-project/sglang.git
cd sglang

# Install the Python packages
pip install --upgrade pip
pip install -e "python[diffusion]"
```

Or replace the pip installation command with `uv pip install -e "python[diffusion]" --prerelease=allow`.

The diffusion implementation lives in [`python/sglang/multimodal_gen`](https://github.com/sgl-project/sglang/tree/main/python/sglang/multimodal_gen).

</Tab>
</Tabs>

## AMD GPUs (ROCm)

For AMD Instinct GPUs (e.g., MI300X), use a ROCm-enabled Docker image from [lmsysorg/sglang](https://hub.docker.com/r/lmsysorg/sglang). The tag below is an example for ROCm 7.0 on MI300X and may lag the latest release tag:

```bash Command
docker run --device=/dev/kfd --device=/dev/dri --ipc=host \
  -v ~/.cache/huggingface:/root/.cache/huggingface \
  --env HF_TOKEN=<secret> \
  lmsysorg/sglang:v0.5.5.post2-rocm700-mi30x \
  sglang generate --model-path black-forest-labs/FLUX.1-dev --prompt "A logo With Bold Large text: SGL Diffusion" --save-output
```

For detailed ROCm system configuration and installation from source, see [AMD GPUs](/docs/hardware-platforms/amd_gpu).

## Moore Threads GPUs (MUSA)

For Moore Threads GPUs (MTGPU) with the MUSA software stack, follow the platform guide first. If the source tree still requires the alternate platform `pyproject` fallback, keep a backup of the default file before switching:

```bash Command
# Clone the repository
git clone https://github.com/sgl-project/sglang.git
cd sglang

# Install the Python packages
pip install --upgrade pip
mv python/pyproject.toml python/pyproject.toml.bak
cp python/pyproject_other.toml python/pyproject.toml
pip install -e "python[all_musa]"
```

## Intel XPU

For Intel Data Center GPU Max or Arc GPUs, follow the Docker instructions in the [XPU installation guide](/docs/hardware-platforms/xpu). The Dockerfile already includes diffusion dependencies.

## Ascend NPU

For Ascend NPU, please follow the [NPU installation guide](/docs/hardware-platforms/ascend-npus/getting-started/installation).

Quick test:

```bash Command
sglang generate --model-path black-forest-labs/FLUX.1-dev \
    --prompt "A logo With Bold Large text: SGL Diffusion" \
    --save-output
```

## Apple Silicon (MPS)

For Apple MPS, follow the instructions below to install from source. If the source tree still requires the alternate platform `pyproject` fallback, keep a backup of the default file before switching:

```bash Command
# Install ffmpeg
brew install ffmpeg

# Install uv
brew install uv

# Clone the repository
git clone https://github.com/sgl-project/sglang.git
cd sglang

# Create and activate a virtual environment
uv venv -p 3.12 sglang-diffusion
source sglang-diffusion/bin/activate

# Install the Python packages
uv pip install --upgrade pip
mv python/pyproject.toml python/pyproject.toml.bak
cp python/pyproject_other.toml python/pyproject.toml
uv pip install -e "python[all_mps]"
```

SGLang Diffusion uses PyTorch MPS. The `all_mps` extra also installs the SRT
MLX backend dependencies; `SGLANG_USE_MLX` applies only to SRT serving.
