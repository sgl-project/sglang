# 前言：写给谁、怎么读

SGLang 是目前开源社区最活跃的高性能大模型推理服务框架之一。它对外提供 OpenAI 兼容的 HTTP API、一套可编程的前端（sglang.lang）、面向训练后阶段（RL）的 rollout 引擎，以及覆盖单卡到千卡集群的分布式推理能力。对于一个 AI 基础设施（AI Infra）工程师来说，SGLang 几乎是一本"活教材"：调度、显存管理、并行通信、性能优化、可观测性这些核心话题都能在代码里找到完整、工业级的实现。

这份文档是围绕**当前仓库代码**（`main` 分支，commit `dd6ddc053`）撰写的源码导读，而不是泛泛的官方文档复述。所有章节都会给出具体的代码路径，方便你对照阅读。

## 目标读者

- **入门级工程师**：熟悉 Python 和 PyTorch，对 LLM 推理有基本概念（KV Cache、batch、decode 等），但没读过大型推理框架的源码。建议从第一部分开始，按顺序读完。
- **进阶工程师**：已经能跑起 SGLang、会写 `sglang.lang` 脚本，想弄明白调度器、显存分配、并行策略是怎么实现的。可以直接读第二部分。
- **进阶级工程师**：正在做生产环境部署、性能调优、二次开发或者把 SGLang 集成进自己的训练/推理平台。第三部分结合生产话题展开。

## 怎么读

1. **对照代码读**。每章都标明了关键文件路径（相对仓库根目录）。看文档时把对应文件打开，边读边跳转。
2. **动手跑**。第 3 章有完整的快速开始步骤，建议先跑起来再读后面的原理章节。
3. **先链路，后细节**。第 6 章给出了"一次请求的完整生命周期"，这是理解整个系统的骨架，值得反复对照。

## 如何运行这份文档

文档由 [mdbook](https://rust-lang.github.io/mdBook/) 管理，位于仓库的 `docs-mdbook/` 目录：

```bash
cd docs-mdbook
mdbook build          # 构建静态站点到 book/
mdbook serve --open   # 本地实时预览（默认 http://localhost:3000）
```
