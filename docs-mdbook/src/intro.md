# 前言：这份文档怎么读

这份文档的目标只有一句话：**让一个没读过推理框架源码的人，从"能跑起来"走到"能读懂调度器、能定位性能问题、能做二次开发"**。

为了做到这一点，文档分成三个严格递进的层级，每一层都有明确的读者和目标：

| 层级 | 适合谁 | 读完能做到 |
| --- | --- | --- |
| 入门（第一部分） | 刚接触 LLM 服务，可能连 KV Cache 是什么都不清楚 | 用自己的话讲清楚一个请求是怎么被服务的；会启动、调用、看日志 |
| 进阶（第二部分） | 已经跑通过，想读懂核心代码 | 能对着源码讲出调度器、缓存、执行器的工作原理，会做简单实验验证 |
| 进阶级（第三部分） | 做生产部署、性能调优、二次开发 | 知道每个设计为什么存在、有什么权衡和失效模式，能独立排查问题 |

## 三个层级的写法约定

- **入门章节**：类比和直觉为主，动手实验驱动，**刻意不出现内部代码路径**。如果某章看完还需要查"这是什么文件"，说明它不合格。
- **进阶章节**：代码走读体。贴真实代码、逐段解释、讲不变量和边界情况，每章配一个可以自己做的实验。
- **进阶级章节**：从"有什么"改为"为什么、权衡什么、怎么失效、怎么救"。会有数字、案例和排查流程，但不再逐行贴代码。

## 关于本文档对应的代码版本

```text
branch: main
commit: dd6ddc053  [Fix] Drop deprecated multimodal processor residency state (#33308)
```

SGLang 迭代很快，代码可能和文档有出入；读源码时以仓库当前代码为准。

## 如何运行这份文档

文档由 [mdbook](https://rust-lang.github.io/mdBook/) 管理，位于 `docs-mdbook/`：

```bash
cd docs-mdbook
mdbook serve --open   # 本地预览 http://localhost:3000
mdbook build          # 生成静态站点到 book/
```

线上版已通过 GitHub Actions 部署到 GitHub Pages，见仓库的 `.github/workflows/mdbook-deploy.yml`。
